# Architecture decision records

Accepted architecture decisions are recorded here independently of
implementation plans. An ADR states *what AIVM commits to* and why; it does
not imply that every related feature or mechanism is implemented.

| ID | Decision | Status | Date |
| --- | --- | --- | --- |
| [ADR-0001](0001-unrestricted-agent-environment.md) | Unrestricted agent administration inside the guest VM | **Accepted** | 2026-10-26 |

Exploratory designs and operational limitations remain under
[`docs/planning/`](../). An accepted ADR must not be read as approving a
specific solution to an open design problem.
