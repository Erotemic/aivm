# Historical core-modules discovery note

This file was an exploratory snapshot from the pre-0.6 codebase and is no
longer maintained as a current module inventory. The old copy described the pre-0.6 single-file store and module layout, which
no longer represent the 0.6 architecture.

Use these maintained sources instead:

- `docs/architecture/README.md` — current subsystem map and state authority;
- `docs/architecture/architecture.yaml` — reviewed module classification;
- `docs/architecture/generated/component-edges.json` — complete generated
  import-edge inventory;
- `docs/source/design.rst` — stable engineering contract.

The generated architecture check resolves the current source tree and is the
source of truth for module relationships.
