# Historical utility-modules discovery note

This file was an exploratory snapshot from the pre-0.6 codebase and is not a
maintained inventory. It predates the current machine-store/profile,
access-control, credential, replay, and privilege layers.

Use the checked architecture inventory instead:

- `docs/architecture/README.md`;
- `docs/architecture/architecture.yaml`;
- `docs/architecture/generated/component-edges.json`;
- `docs/architecture/generated/compatibility-inventory.md`.

The architecture check is deliberately tied to the Python source tree so
renamed or deleted modules do not leave a second stale handwritten index.
