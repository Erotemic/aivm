# Developer material

This directory holds the tools and chronology of AIVM development, rather
than the project's active design backlog:

- [`devcheck/`](devcheck/) — diagnostic scripts, reproduction cases, and
  incident investigations; duplicate EMFILE reports are retained until a
  separate evidence-preserving consolidation.
- [`journals/`](journals/) and [`journal.md`](journal.md) — chronological
  development logs; old path mentions are historical records.
- [`design/programatic/command_policy.py`](design/programatic/command_policy.py)
  — executable policy experiment, not an active prose proposal.

The former `dev/design/future/` roadmap and designs are now available through
[`docs/planning/README.md`](../docs/planning/README.md). The original dated
roadmap index is preserved in
[`docs/history/2026-07-future-design-roadmap.md`](../docs/history/2026-07-future-design-roadmap.md).
